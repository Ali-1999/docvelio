# Docvelio SEO Keyword and Search-Intent Map

**Prepared:** 30 October 2026. **Source:** Docvelio's actual route and supported tool inventory, plus the user's ten SEO slides. These keywords are *hypotheses*, not verified search volumes or Google Search Console query reports.

Do **not** interpret this table as evidence of positions, search demand, traffic or difficulty. Validate with Google Search Console, Keyword Planner, real autocomplete and top-ten page reviews before committing to expensive content production.

## Four types of search intent

- **Informational:** How-to and explanatory guides. Give a clear answer, then steps, limitations and related tool links.
- **Navigational:** Brand queries such as “Docvelio PDF editor”; ensure the homepage, About, Contact and branded page titles help people find the right site.
- **Commercial investigation:** Comparisons such as “best free PDF editor for adding annotations”. Provide an honest comparison of actual capabilities, not invented competitors' scores.
- **Transactional/task completion:** “merge PDF files online”, “resize image 300x300”, or “calculate CBM 40ft”. Put the working tool before long explanations.

## Five-stage research workflow from the uploaded slides

1. Gather real questions from support emails, contact form queries and user feedback. Do not expose private messages.
2. Check Google autocomplete and People Also Ask for these primary clusters, across relevant languages and countries. Capture exact wording and date rather than fabricating suggestions.
3. Check monthly search estimates and difficulty *when* Keyword Planner or a verified SEO dataset is connected. Use country and language as filters; a blank metric is preferable to made-up volume.
4. Prioritise useful long-tail variants by user need and page fit, not a rigid 3-word threshold or fictional “easy to rank” labels.
5. Review the actual top-ten results for each priority phrase, their tool capabilities, accessibility, demonstration quality, limitations, and content gaps. Avoid copying competitor text.

## Editorial guardrails

- Put the working tool and a concise answer above or near the main explanatory content.
- Use one descriptive H1; write unique titles and summaries for actual users. **Google has no fixed 50–60-character title-tag requirement.** The search appearance can be rewritten.
- Link in context using understandable labels. Do not repeat the same phrase unnaturally.
- Never claim ranking, volume, competitiveness or search traffic without a measured source.
- For nine translated languages, have a competent reviewer evaluate terminology and culturally appropriate examples before expanding.
- Prioritise the usefulness and distinctiveness of the existing 581 URLs before publishing additional thin pages.

## Measurement fields to fill from Search Console

Date range; market; language; query; page URL; indexed status; impressions; clicks; CTR; average position; desired action; next test; implementation date. Obtain metrics from a connected account or an authorised CSV export. **No measurements were inferred or invented.**
