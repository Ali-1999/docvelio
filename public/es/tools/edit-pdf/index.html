Cómo utilizar esta herramienta

  1. Selecciona el documento de tu dispositivo.
  2. Las anotaciones son capas visuales, no edición del texto original ni censura segura.
  3. Guarda el resultado y revisa el archivo descargado.
Limitaciones importantes: Cubrir texto no es una censura segura. No se admite editar el texto original ni todos los alfabetos en las anotaciones.

Preguntas frecuentes

¿Se modificará mi archivo original?

No. Se genera un archivo nuevo. Conserva el original.
