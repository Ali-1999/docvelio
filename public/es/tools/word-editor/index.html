A lightweight DOCX editor

Handles common headings, formatting, paragraphs, lists and basic tables. Complex page layouts, tracked changes and some embedded content may change. Keep a copy of important originals.

Cómo utilizar esta herramienta

  1. Selecciona el documento de tu dispositivo.
  2. Abre DOCX o TXT o escribe desde cero; revisa el formato exportado.
  3. Guarda el resultado y revisa el archivo descargado.
Limitaciones importantes: El editor funciona mejor con texto y tablas sencillas; el diseño complejo puede cambiar.

Preguntas frecuentes

¿Se modificará mi archivo original?

No. Se genera un archivo nuevo. Conserva el original.
