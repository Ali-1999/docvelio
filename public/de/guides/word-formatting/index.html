Word-Formatierung bewahren

Tipps zu Datenschutz, PDF-Seiten und Word-Formatierung. Bewahren Sie das Original auf. Schriftarten, Layouts oder geschützte Dateien können Probleme verursachen.

So verwenden Sie dieses Tool

  1. Wählen Sie ein Dokument auf Ihrem Gerät aus.
  2. DOCX oder TXT öffnen oder neu schreiben; Format nach dem Export prüfen.
  3. Legen Sie Optionen fest und prüfen Sie die Auswahl.
  4. Speichern Sie das Ergebnis und prüfen Sie den Download.

Wichtige Einschränkungen

Der Editor eignet sich für einfachen Text und Tabellen; komplexe DOCX-Layouts können sich ändern.

Die Dokumente werden lokal verarbeitet; Bibliotheken werden von externen CDNs geladen.
