So verwenden Sie dieses Tool

  1. Wählen Sie ein Dokument auf Ihrem Gerät aus.
  2. Anmerkungen liegen über dem PDF; sie ändern keine Quelltexte und schwärzen nicht sicher.
  3. Speichern Sie das Ergebnis und prüfen Sie den Download.
Wichtige Einschränkungen: Weißes Überdecken ist keine sichere Schwärzung. Ursprünglicher Text und einige Schriftsysteme lassen sich nicht bearbeiten.
