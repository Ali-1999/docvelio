Free Barcode Generator and Printable Labels

Generate Code 39, Code 128, EAN-13, UPC-A or ITF linear barcodes locally in your browser. Save clean, scalable SVG artwork or print product labels. No file uploads, external barcode API, login or watermark.

Barcode generation runs locally · No external barcode service

How to use

Enter uppercase letters, numbers or Code 39 symbols (- . space $ / + %). The tool adds the required start and stop characters automatically. Download SVG for logos, packaging or documents; use Print labels to print multiple A4 labels.

Supported formats: Code 39, Code 128, EAN-13, UPC-A and Interleaved 2 of 5. EAN and UPC accept a missing check digit and calculate it locally. It is not an EAN/UPC retail numbering service, a GS1 certification tool or a shipping-carrier integration. Check print quality with your actual scanner before production use.

Bulk CSV labels

Paste or upload a CSV with columns value,title. Generate up to 100 labels locally without uploading your data.

Scan barcode with camera

Uses the browser’s built-in BarcodeDetector when available. Images and camera frames remain on your device. Requires a secure connection and camera permission.
