How to edit and download a PDF

  1. Open an existing PDF using the file picker. The first page appears on screen.
  2. Choose Text and click where text should appear. Or use Pen to draw, Highlight to mark a passage, or Cover to hide content visually.
  3. Navigate to other pages and add more marks if required. Undo removes your most recent edit on the current page.
  4. Choose Save edited PDF. A green Download edited PDF link appears beneath the editor, along with Open edited PDF.
Important limitation: This is an annotation-style editor. It adds text and drawing overlays; it does not directly rewrite existing text inside paragraphs. The Cover tool uses an opaque white shape and does not remove hidden underlying PDF content. Never use it to redact private information.

Frequently asked questions

Can I really edit PDF text?

You can add new text. Editing original PDF characters and reflowing existing text requires a more advanced editing engine and is not supported here.

Can I download the edited PDF?

Yes. After choosing Save edited PDF, use the persistent Download edited PDF button.

Are scanned PDFs supported?

Most PDFs, including scanned documents, can be annotated. This tool does not perform OCR or make scan text editable.

Why do some characters fail when saving?

The included simple PDF font supports Western Latin text and punctuation, but not all international scripts or emoji. Use basic English text or extend the editor with embedded fonts.

Annotate and review a PDF while keeping the original

For feedback on a proposal, add a note beside a heading, highlight a passage or use the pen to point to a figure. Download the revised file under a distinct filename so the unedited original is easy to recover. Try a short test document first to confirm that fonts and annotations export correctly.

The Cover tool draws over material visually; it is not secure redaction, because underlying PDF content may remain extractable. This editor also does not rewrite arbitrary embedded text objects. For confidential information, use purpose-built redaction software and check the final file independently.
