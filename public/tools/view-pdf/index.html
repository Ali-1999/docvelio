How to open and download a PDF

  1. Select a PDF from your phone or computer.
  2. Use Previous, Next and zoom controls to inspect pages.
  3. Choose Download original PDF to save a copy, or Edit PDF to add text or markings.

What does the PDF viewer support?

This free viewer displays regular PDF files without creating an account. It is designed for reading, page-by-page review and downloading the selected original. It does not automatically open password-protected files, and some complex or unusually large documents may be unsupported.

Privacy note: Your selected PDF is processed locally by the JavaScript app; it is not sent to an application backend. Third-party script hosting still receives ordinary network metadata.

Frequently asked questions

Does it upload my document?

No application upload is performed by this tool. Browsers download the PDF.js library and worker from a third-party CDN.

Can I download after viewing?

Yes. The green Download original PDF link appears above the preview after you open a document.

Review a document before sending it

A preview is useful when you want to check that a contract, application or attachment opens correctly without installing another program. Browse the pages and inspect small text using the zoom controls. You can download the original file again without changing its content.

Some protected PDFs, embedded multimedia or specialised interactive forms may not display as expected. If a document is legally important, compare the preview with a trusted desktop reader. The download option saves the file you originally selected; it does not add annotations or convert the file.

To mark up pages, use Edit PDF.
