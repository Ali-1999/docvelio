Split PDF and Extract Pages

Save selected pages or page ranges as a new PDF without uploading your document.

Files are processed in your browser. No PDF contents are sent to this website by the tool.

How to split pdf and extract pages

  1. Choose one PDF.
  2. Enter pages such as 1-3,5,8-10.
  3. Click Extract Pages to save one new PDF containing your selection.

When this tool is useful

Page extraction helps when you need only a chapter, receipt, or appendix from a larger document. Ranges are one-based: page 1 is the first page in the file, even if a printed page number says something different. The resulting download contains only the selected pages, ordered by original page position.

Before sharing: Open the output and verify page order, text, images and formatting. This is a straightforward utility, not a replacement for professional document review.

Frequently asked questions

Can I create multiple PDFs at once?

This starter exports one PDF with selected pages. Separate downloads are not yet supported.

How do page ranges work?

Use commas for separate pages and a hyphen for an inclusive range, for example 2-4,7.

Processing depends on your device and browser memory. Very large documents may take longer or fail.

Share only the pages someone needs

Extracting a page range is useful when a colleague needs only the invoice pages from a larger report, or when you want to separate a chapter from a longer file. Use page numbers from the PDF file itself rather than numbers printed on the pages: a cover page may make those numbers different.

This tool creates a single output file containing the selected pages, not one file per page. If you are removing unrelated confidential material, open the exported file and verify that the pages you intended to exclude are not present. Check bookmarks and internal references before sharing.

For the opposite operation, try Merge PDF. For unwanted pages, see Remove PDF Pages.
