Modifier un PDF avec précaution

Conseils sur la confidentialité, les pages PDF et le formatage Word. Gardez l’original : certaines polices, mises en page ou fichiers protégés peuvent poser problème.

Comment utiliser cet outil

  1. Sélectionnez un document sur votre appareil.
  2. Les annotations sont des couches visuelles, pas une modification du texte source ni une suppression sûre.
  3. Réglez les options et vérifiez votre sélection.
  4. Enregistrez le résultat et vérifiez le fichier téléchargé.

Limites importantes

Le masquage visuel ne supprime pas les données. La modification du texte source et certaines écritures ne sont pas prises en charge.

Ces outils traitent les fichiers localement ; certaines bibliothèques sont chargées depuis des CDN externes.
