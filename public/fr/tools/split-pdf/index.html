Extraire des pages PDF

Extrayez les pages de votre choix dans un nouveau PDF.

Les fichiers sélectionnés sont traités sur votre appareil.

Comment utiliser cet outil

  1. Sélectionnez un document sur votre appareil.
  2. Indiquez les pages avec des virgules et tirets, par exemple 1-3,5.
  3. Enregistrez le résultat et vérifiez le fichier téléchargé.
Limites importantes: Gardez l’original : certaines polices, mises en page ou fichiers protégés peuvent poser problème.

Questions fréquentes

Mon fichier original sera-t-il modifié ?

Non. Un nouveau document est créé. Conservez l’original.

Vérifiez les documents téléchargés avant de les partager.
