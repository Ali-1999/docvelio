Comment utiliser cet outil

  1. Sélectionnez un document sur votre appareil.
  2. Les annotations sont des couches visuelles, pas une modification du texte source ni une suppression sûre.
  3. Enregistrez le résultat et vérifiez le fichier téléchargé.
Limites importantes: Le masquage visuel ne supprime pas les données. La modification du texte source et certaines écritures ne sont pas prises en charge.
