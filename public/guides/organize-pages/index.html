How to organise PDF pages without losing track

Organising a PDF is easiest when you decide the intended reading order before making changes.

Start with a page inventory

Open the original PDF and note its total page count. Some documents contain a cover, introduction and appendices that use printed page numbers different from their actual PDF positions. PDF tools generally count from the first physical page in the file, so use that count when specifying ranges.

Choose the right operation

Use Merge PDF to combine separate source files into one document. Use Split PDF when you need a smaller set of pages. Use Remove Pages to discard unwanted pages from a long scan. Rotation fixes sideways pages. If you need to correct a single page, extract it and then merge it with the rest of the document.

Maintain a reviewable original

Save the new PDF with a descriptive filename, such as report-final-pages.pdf. Keep the original file until you have compared both versions. Check links, bookmarks and any cross-references, because changing the number or order of pages can make a document less useful even when every visible page looks correct.

Check downstream needs

A PDF used for printing may need consistent page sizes and orientation; a PDF sent by email may need reduced file size. If your PDF has signatures or certification, editing pages may invalidate them, so consult the issuing organisation before making changes.
