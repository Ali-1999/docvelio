TikTok Video Downloader & Original MP4 Saver

Check a TikTok video link, download a public video you have permission to save when our backend is available, or keep a clean copy of your own original MP4 file. The local file saver does not upload your video or add a watermark.

What this tool does not do: It does not access private or protected media or guarantee watermark-free files from arbitrary TikTok links. Public link downloads use a best-effort Cloudflare Worker fallback and may fail when TikTok restricts access.

1. Check a TikTok video link

Paste a public TikTok share URL. Open the original post to use TikTok’s built-in Save Video option, when available.

Retrieving public video…

The download option first uses Docvelio’s Cloudflare Free best-effort public-video retrieval. If a self-hosted backend is configured, it is used instead. TikTok may block either method, and watermark-free output is not guaranteed. If unavailable, choose Share → Save Video on TikTok when the creator allows it.

2. Save your original MP4

Have an unwatermarked original export from your own video editor? Select it here to preview and save that exact file locally.

Up to 500 MB. Files stay in your browser. This preserves the selected file; it does not remove an existing embedded watermark.

How to save TikTok videos for educational use

  1. Check permission. Save videos you own or have permission to use. Educational purpose alone does not automatically grant redistribution rights.
  2. For a public TikTok post: open the link in TikTok and look for Share → Save Video. If that option is absent, the creator may have disabled downloads.
  3. For a watermark-free original: export from your editing application before uploading to TikTok, or use the clean original file you already have.
  4. For lessons or presentations: keep the creator’s attribution and verify that your intended reuse is permitted.

What is the difference between a TikTok share link and an original MP4?

A TikTok URL points to a video on TikTok’s platform. It is not a direct MP4 file address. Docvelio first attempts a public permitted MP4 using Cloudflare Workers Free; if configured, a separately hosted yt-dlp backend takes priority. Both are subject to upstream availability. TikTok’s official developer display interfaces are for playback and metadata rather than unrestricted original media downloads. A locally stored MP4 is already a video file and can be saved again without creating a new watermark.

Different creators and regions may see different options. Video quality, availability, reuse rights and download settings remain controlled by the source and its owner. This page does not claim to work around those restrictions.

Private, free, browser-based file handling

When you select an original video from your device, Docvelio creates a temporary local preview and download link with your browser’s Blob URL support. It does not send the selected video to Docvelio servers or to a paid media-downloader API. The link-check function validates a TikTok hostname and opens the corresponding page in a new tab. If you request a permitted link download, the TikTok URL is sent to our Cloudflare Worker, which may retrieve publicly accessible media directly or use a configured backend. Cloudflare limits apply.

Modern browsers may handle large files and downloads differently, especially on iOS. If saving is blocked, use your device’s native Share or Save to Files controls.

Frequently asked questions

Does this website remove the TikTok watermark automatically?

No. If the file already includes an embedded watermark, downloading the same file does not remove it. Start with an original clean export for watermark-free results.

Can I paste any TikTok link and receive a downloadable MP4?

No. Public share links do not guarantee an accessible media file. This page directs you to TikTok’s official download option when available.

Is the original MP4 saver free?

Yes. It runs entirely in your browser with no account, subscription, API charge or upload.

Will my videos be saved on Docvelio servers?

No. The local file selection and download are handled by your browser, and a temporary object URL is cleared when you remove the file or leave the page.

Can I use a downloaded video in my school project?

Confirm the copyright permission and school policies. Attribution alone is not always a substitute for permission.
