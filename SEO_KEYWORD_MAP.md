## Homepage

Primary intent: **free PDF and Word tools online**. Avoid trying to rank the homepage for every individual PDF operation; use a separate focused tool page for each action.

## Priorities

1. Make tools reliable; original, helpful instructions should match what each tool really does.
2. Add screenshots and step-by-step examples from actual tool tests; don’t use filler or copied articles.
3. Use descriptive internal links from guides to tools and between adjacent workflows.
4. Evaluate search impressions, clicks, rankings and queries in Search Console; revise titles based on observed performance.
5. Use PageSpeed Insights and mobile usability tests to catch performance and accessibility problems.
6. If you later add PDF compression, OCR or PDF-to-Word, build the features first and create truthful dedicated pages only when working.
